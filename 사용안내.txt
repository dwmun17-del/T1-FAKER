훈련생 출결 · 상담 관리 — 시험용 첫 버전

시작하기
1. TrainingManager.exe를 두 번 클릭합니다. Windows용 프로그램입니다.
2. 처음에는 '가상 데이터 추가'로 시험해 보세요.
3. 출결 탭에서 날짜를 선택하고 출결과 사유를 입력한 후 '출결 저장'을 누릅니다.
4. 상담 기록 탭에서 훈련생을 선택하고 '상담 작성'을 누릅니다.
5. 프로그램을 닫았다 다시 열어 시험 자료가 유지되는지 확인하세요.
6. '백업 저장'으로 백업한 후 가상 자료 상태에서 '백업 복원'도 시험하세요.

자료와 백업
- 인터넷 전송 기능은 없습니다.
- 자료 위치: %LOCALAPPDATA%\VocationalTrainingManager\records.dat
- 실행 파일을 이동하거나 새 버전으로 교체해도 같은 Windows 계정의 자료를 사용합니다.
- 백업은 현재 PC의 동일 Windows 사용자 환경에서 복원하기 위한 것입니다.

사용 범위
- 기관의 실제 훈련생·상담 정보를 입력하기 전 내부 프로그램 사용 및 개인정보 보관 기준을 확인하세요.
- 기관 보안 설정으로 실행이 차단되면 임의로 차단을 해제하지 말고 전산 담당자에게 사용 가능 여부를 확인하세요.
